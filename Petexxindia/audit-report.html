1. CRITICAL — Fix Immediately

Hidden spam link injection (site compromised)

Critical CRIT-01
Location https://www.petexxindia.com/about-us/ — inside the company description paragraph. Evidence
<a style="text-decoration: none; color: #333;" href="https://bestessayes.com/buy-research-papers/">sell term papers</a>
Problem An invisible link (unstyled anchor text, matching text color, no underline) points to an essay-mill spam domain. Classic black-hat SEO injection delivered via an abandoned nulled theme or vulnerable plugin. Google treats manipulative outbound links as a webspam signal and can apply manual action or deindex the domain.
Fix: Remove the link, scan all wp-content files for further injections, rotate all admin credentials, replace the theme, install a firewall/monitoring plugin (Wordfence/Sucuri) and request Google reconsideration if a manual action exists in Search Console.

HTTP version serves full content — no redirect to HTTPS

Critical CRIT-02
Location Site-wide, server configuration. Evidence
GET http://www.petexxindia.com/ → HTTP/1.1 200 OK (no 301 to https://)
Problem The insecure HTTP URL returns the complete page instead of a 301 redirect. Users can browse unencrypted; search engines may index both protocol variants (duplicate content, split ranking signals); forms and emails are exposed to interception.
Fix: Add a permanent 301 redirect HTTP→HTTPS at the Apache/vhost level, then force HTTPS for all hosts (www and non-www canonicalised to one).

60+ mixed-content resources loaded over plain HTTP

Critical CRIT-03
Location Every template. Evidence
Homepage: 47 × src="http://..." 3 × href="http://..." Products: 7 × src="http://..." Portfolio: 8 × src="http://..." 3rd-party: http://kloe.select-themes.com/wp-content/uploads/2015/12/pattern.png
Problem On an HTTPS page browsers block or warn on insecure subresources — broken images, insecure-connection warnings in the address bar, loss of buyer trust (the audience here is overseas importers). Assets still point at the theme vendor's demo domain over HTTP: if that domain dies or changes hands, parts of the site break.
Fix: Run a search-replace of http://www.petexxindia.com → https:// across post content, and download all kloe.select-themes.com assets locally into the child theme. Enable "HTTPS mixed-content" scanning after.

All security headers missing

Critical CRIT-04
Evidence
Strict-Transport-Security : (missing) Content-Security-Policy : (missing) X-Frame-Options : (missing) X-Content-Type-Options : (missing) Referrer-Policy : (missing)
Problem No HSTS → HTTPS can be silently downgraded on first visit. No CSP → the already-present injected script/link can execute unchallenged. No X-Frame-Options → clickjacking risk. No X-Content-Type-Options → MIME-sniffing risk.
Fix: Add the five headers in .htaccess (HSTS with 1-year max-age + includeSubDomains once HTTPS redirect is in place; CSP starting in Report-Only mode).
